# CosmicVerse

Platform forum komuniti untuk menulis, berkongsi, dan menghayati puisi.

## Features
- Register & Login
- Tulis, edit & delete puisi
- Kategori & tag puisi
- Like & komen
- Cari puisi, user & tag
- Profile page
- Senarai ahli

## Tech Stack
- Python & Flask
- SQLite
- HTML & CSS

## Installation

1. Clone repository
```bash
git clone https://github.com/irfnn09/cosmicverse.git
cd cosmicverse
```

2. Create virtual environment
```bash
python -m venv venv
venv\Scripts\activate
```

3. Install dependencies
```bash
pip install -r requirements.txt
```

4. Create `.env` file


5. Run
```bash
python app.py
```
